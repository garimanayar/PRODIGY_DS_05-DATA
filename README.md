# 🚗 Prodigy Infotech Task-03: US Traffic Accident Data Analysis

This project is part of the Prodigy Infotech Internship. The objective is to analyze US traffic accident data and identify patterns related to:

- 🛣️ Road conditions  
- ☁️ Weather  
- 🕐 Time of day  
- 📍 Accident hotspots  
- ⚠️ Contributing factors  

---

## 📊 Dataset

- Source: [Kaggle - US Accident EDA by Harshal Bhamare](https://www.kaggle.com/code/harshalbhamare/us-accident-eda)
- The dataset contains records of traffic accidents in the United States with features like location, weather, severity, time, etc.

---

## 📌 Objectives

1. Explore the dataset and perform data cleaning.
2. Analyze the impact of weather, road conditions, and time on accidents.
3. Identify accident-prone zones (hotspots).
4. Visualize patterns using plots and maps.

---

## 🛠️ Tools & Technologies

- Python 🐍
- Pandas & NumPy
- Matplotlib & Seaborn
- Plotly & Folium
- Jupyter Notebook

---

## 📈 Visualizations

- Heatmaps of accident locations  
- Pie charts/bar graphs for weather & road condition impact  
- Time series analysis (hour of day, day of week)  
- Maps showing hotspots using `Folium`
